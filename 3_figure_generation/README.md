
### This folder contains all the R codes that were used to generate the main figures in the manuscript and those in the Supplementary Material. 

#### To generate the figures: 
  1. OPEN the R project figure_generation.Rproj
  2. RUN the script file of the figure (for example, for figure 1, open figure_1.R) you want to generate.

     All the helping functions are in the functions folder, data in the data folder, pre-calculated values (to save time, but the relevant scripts are still available),
      such as kdes and pooled ct values are stored in the pre-calculations folder. Synthetic data generated from the ABM is in the synthetic data folder.
